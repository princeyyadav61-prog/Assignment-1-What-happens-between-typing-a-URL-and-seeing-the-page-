Meta Tags Audit & Optimization

A reference guide for inspecting and configuring HTML meta tags.

1. Primary SEO Meta Tags

These tags tell search engines what your page is about, who created it, and whether it should be indexed.

  • Charset: Defines character encoding (`<meta charset="UTF-8">`).
  • Viewport: Ensures proper mobile responsiveness (`width=device-width, initial-scale=1.0`).
  • Description: Summarizes page content for search engine results pages (SERPs).
  • Robots: Instructs crawlers whether to index and follow links.
